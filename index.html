01 / THE JOB

A chat answers. An agent job owns the next step.

Free AI is excellent at producing text from context you provide. We build the missing system around it so work can arrive, move, stop at the right boundary, and finish with evidence.

WHAT GETS INSTALLED

Six parts turn inference into operations.

01 / INTAKEA real source of work

An inbox, form, folder, database event, support queue, or schedule supplies new jobs. Nobody has to remember to prompt it.

02 / STATEA queue that remembers

Every item has an identity and status. Retries do not create duplicates. The agent can stop today and resume tomorrow.

03 / TOOLSAccess to the systems that matter

The job can look up records, compare sources, create bounded changes, and return evidence from the same tools your team uses.

04 / POLICYWritten authority

Each action is classified: do it, ask first, or never do it. Permissions enforce the boundary instead of relying on a polite prompt.

05 / EVALUATIONA measurable definition of good

Historical cases become tests. Shadow runs show where the agent and operator disagree before real work depends on it.

06 / RECOVERYProof, retries, and handoff

The job checks that the action worked. Failures stay visible with a reason, an owner, and a safe next step.
