# 0tomait launch system

This folder turns the current offer, client record, executable demo, and audit into a
repeatable founder-led sales motion. The target is not generic traffic. The target is a
steady supply of real process walkthroughs with owners and operations leaders who can
show work falling between systems.

## First 30-day outcome

- 20 individually selected warm contacts reviewed by Brandon.
- 5 introduction requests reviewed and sent.
- 5 process walkthroughs held.
- 2 paid AI Leverage Maps or scoped pilot proposals.
- 1 paid Agent Job Pilot.
- Enough buyer language to choose one narrow vertical or workflow for the second month.

One paid pilot is the base target. Four new pilots in a month is not yet the operating
target: four overlapping three-week builds would create a delivery bottleneck. A healthy
first scale target is one to two pilots plus maps and recurring care. Raise that only after
three pilots establish actual delivery hours, support load, and reusable implementation
patterns.

## Weekly operating rhythm

### Monday — evidence and selection

1. Review the pipeline and the prior week's scorecard.
2. Select five warm contacts, five target accounts, and two potential partners.
3. For each person, record one relationship or process fact. If there is no fact, do not
   pretend there is one; ask a process question instead.
4. Choose the week's one proof asset: demo, client account, audit, or a lesson from a real
   walkthrough.

### Tuesday and Wednesday — conversations

1. Send the approved messages manually.
2. Reply as a person, not as a sequence engine.
3. Ask for the last real item, not a theoretical list of AI use cases.
4. Record buyer language, systems, frequency, failure cost, and the definition of done.

### Thursday — public proof

1. Publish one useful teardown or classification post.
2. Use one claim and one call to action.
3. Link to a tracked website URL from [utm-links.csv](utm-links.csv).
4. Spend the rest of the session commenting usefully where target buyers already talk.

### Friday — qualification and learning

1. Move records to the correct pipeline stage.
2. Count walkthroughs, qualified opportunities, maps, proposals, wins, and cash collected.
3. Classify every opportunity as prompt, built-in feature, ordinary automation, existing
   product, or agent job.
4. Change one variable for the next week. Do not rewrite the entire offer from a thin
   sample.

## Launch gates

- [x] Public site states the AI Leverage Map and Agent Job Pilot clearly.
- [x] Public site represents four real engagements without inventing outcomes.
- [x] Contract-to-kickoff demo completes with receipts and zero open exceptions.
- [x] Pricing and scope are public.
- [x] Calendar destination works from the public site.
- [ ] Cloudflare Web Analytics enabled for the Pages project.
- [ ] Google Calendar booking form asks: “How did you hear about 0tomait?”
- [ ] LinkedIn headline and About section match the live offer.
- [ ] First 20 real warm contacts added to the private pipeline and approved.
- [ ] First five messages sent by Brandon.

Sending, posting, enriching contacts, or changing external records always requires a human
review. Drafting, research, classification, and local reporting can be automated.

## Tools now versus later

Use the local CSV pipeline, Google Calendar, the website, LinkedIn, and direct messages for
the first wave. They are enough to prove whether the offer earns conversations.

Apollo is useful after it is connected and after the first ten walkthroughs sharpen the
ICP. Use it then for account discovery and research; do not buy contact data to compensate
for an unclear message. HubSpot becomes useful when follow-up volume exceeds the local
pipeline. Supermetrics becomes useful only after multiple traffic or paid channels create
data worth blending. Neither is required to land the first client.

## Source-of-truth rules

- A real engagement may be named only at the level already approved on the public site.
- The Kymber Brockbank quote may be used as published.
- River / DORE, Keys + Wasserman, and Trash Dash prove commercial engagement, not an
  invented outcome.
- The contract-to-kickoff scenario is always labeled composite data.
- Every external draft is marked **Needs review** until Brandon sends or publishes it.
