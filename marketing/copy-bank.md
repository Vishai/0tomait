## First newsletter edition — The Job After the Prompt

**Title:** The last real item is more useful than a list of AI ideas

Most AI discovery starts with a bad question: “Where could we use AI?”

That question produces a long list because language models are excellent at producing
lists. It does not tell you which improvement will survive contact with the business.

Start with the last real item instead.

Where did it arrive? What gave it an identity? Which systems did someone check? Where did
judgment enter? Which action moved it forward? What needed approval? What proved the job
was finished? What happened when data was missing or a tool failed?

Those answers separate five different products people casually call “AI automation.”

1. A prompt, when the useful result is an answer or draft.
2. A built-in feature, when software you already own handles the job.
3. Ordinary automation, when every input follows the same known path.
4. An existing product, when a vendor already owns the workflow.
5. An agent job, when work keeps arriving, context lives across systems, decisions vary,
   actions need boundaries, and the real outcome can be verified later.

The classification matters because custom work is expensive in more ways than its price.
It creates something that must be operated, trusted, recovered, and eventually maintained
by someone who did not build it.

My rule is simple: earn the right to propose an agent by first trying to disqualify it.

If you want to test that rule, send me the last real item—not a hypothetical process map.
