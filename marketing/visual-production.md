# Commercial visual production

The launch does not need a model zoo. It needs one commercially safe scene generator,
exact-text brand assets, and a repeatable way to turn proof into short motion.

## Model decision

### Use now — FLUX.2 Klein 4B

The machine already holds the 4-bit Apple-Silicon cache at roughly 24.3 GB. The upstream
4B model and the local model card are Apache 2.0, so local commercial use requires no
monthly model fee or approval. The installed `mflux` runtime supports text-to-image,
single-reference editing, and multi-reference editing.

Use it for:

- realistic operations scenes and visual metaphors;
- background plates and b-roll;
- variations from an approved reference image;
- campaign concepts where exact written text will be added later in HTML or graphics.

Do not ask the model to draw the final logo, price, UI, or legal claim. Exact text belongs
in code-generated social cards or the website.

### Internal ideation only — Studio Qwen 2.1 Turbo

The Studio's current built-in picture model is Qwen 2.1 Turbo. The Studio integrates it,
but its displayed Qwen Research License is non-commercial. It is useful for internal
storyboards and concept scouting. Do not publish its output in 0tomait commercial
marketing unless a separate license review establishes permission.

### Do not install yet — MOSS-Image and FLUX3-K

MOSS-Image is a useful future addition for image-native lettering, but it is an additional
roughly 28 GB and slower than the already-cached FLUX model. Exact campaign typography is
more reliable in HTML. Install MOSS only after three real production sessions show a need
for lettering inside the generated scene.

FLUX3-K is a much larger download with different license conditions. It does not solve a
launch bottleneck today.

## Initial visual set

1. **The stranded handoff:** a signed agreement sitting between five disconnected work
   stations; no readable brand names or generated text.
2. **The approval boundary:** a clean operational control room with one amber hold gate
   and several green verified paths.
3. **The last real item:** one work item moving from inbox to records, billing, project,
   and calendar with a visible evidence trail.

For each scene, generate four variations and keep only an image that makes the process
clear without a caption. Add the headline, offer, URL, and logo afterward using the
brand-card template.

## Motion with Imagination Studio

Use the Studio to plan and assemble 15-to-30-second proof clips, but keep licensing
separate for every model involved. The safest launch clip is a screen-led motion piece:

1. Start on the live demo's “signed but stranded” state.
2. Animate the saved execution timeline.
3. Hold for one second on the approval boundary.
4. End on “deposit paid / project ready / kickoff booked / zero exceptions.”
5. Close with the exact-text card: “Find where AI pays off. Then give it the job.”

This needs no synthetic customer, voice, or generated claim. Use commercial-safe music
and video only after their licenses are recorded.
